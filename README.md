## 2. 실행 방법

### PC
1. `index.html`을 더블클릭하면 바로 열립니다(`file://` 모드, 데이터는 내장본 사용).
2. 쇼츠가 확실히 재생되게 하려면 폴더에서 임시 서버를 띄워 여는 것을 권장합니다.

```bash
cd metaverse-gallery
python3 -m http.server 8765
# 브라우저에서 http://localhost:8765/index.html
```

### 휴대폰
- 같은 와이파이에서 PC가 서버를 띄운 뒤, 폰 브라우저로 `http://<PC IP>:8765/index.html` 접속
- 또는 `index.html` 파일 하나를 폰으로 보내 열기(이 경우 유튜브 임베드가 막힐 수 있어 `YouTube에서 직접 보기` 링크를 함께 제공합니다)

> 음성 입력(말로 쓰기)과 실시간 음성방은 **HTTPS(또는 localhost)** 에서만 마이크를 쓸 수 있습니다. `file://`에서는 안내 문구만 뜨고 에러가 나지 않습니다.

### 조작
- **PC**: `WASD`/방향키 이동(화면 기준), 마우스 드래그로 시점, 판넬 클릭 또는 `E`로 열기, `V` 1인칭/3인칭, `G` 방명록
- **모바일**: 왼쪽 아래 조이스틱(82px) 이동(밀어넣은 방향 = 화면에서 그 방향), 화면 드래그 시점, 판넬 직접 탭
- **두 손가락 확대·축소**: 전시관 화면에서 두 손가락을 **벌리면 가까이(최대 3.2×)**, **오므리면 멀리(최소 0.65×)** 보입니다. 1.0× 가 아니면 화면 오른쪽에 `🔍 1.8× · 초기화` 알약이 떠서 한 번 누르면 원래대로 돌아옵니다. 핀치가 끝나고 손가락 하나를 떼도 시점이 튀지 않고, 확대한 채로 걸어 다닐 수 있습니다. (PC: `Ctrl`(⌘) + 마우스 휠)
- **안내 알약**: 가까운 부스가 있으면 화면 맨 아래 가운데에 `항셍지수 · 보기` 같은 한 줄 알약이 뜹니다. 알약을 눌러도 그 부스의 쇼츠가 열립니다(캐릭터를 가리지 않는 자리).
- **상단 바**: 오른쪽 `✏️ 판넬 편집`(2~5번 판넬 고르기) · `📺 뉴스TV` · `전체(중앙홀)` · 통화 · 지수 · 금리 · 금속 · 에너지 · 농축산물 · 안내데스크 버튼을 누르면 그 방 문 안쪽으로 이동하고, 이어서 종목(골드 5/5 …)을 탭하면 그 부스 정면으로 이동합니다.
- **📺 뉴스 TV**: 중앙홀 남쪽 입구 벽 **오른쪽 끝**의 세로형 TV 화면을 탭/클릭하거나, TV 앞에서 `E` 또는 아래 알약 `📺 국제상품 뉴스 TV · 크게 보기` 를 누르면 크게 보기가 열립니다. 3D 화면에서도 두 손가락(0.65~3.2×)·`Ctrl`+휠로 TV 를 당겨 볼 수 있습니다(자세한 내용은 `10. 📺 뉴스 TV`).
- **오른쪽 단추 줄**(위→아래): `👁 1인칭` → `✍️ 방명록` → (방문자가 있으면) `👋 손흔들기`·`🙇 인사`·`🎙️ 음성 대화`. 이전의 `? 도움말` 단추는 없앴습니다(2026-11-20). 폰에서 인사 단추가 뜨면 안내 알약이 그 위로 40px 올라가 서로 겹치지 않습니다.
- **앉기**: 미팅 라운지 의자를 탭하거나, 의자 옆에서 `🪑 앉기` 버튼(또는 `E`)을 누르면 로봇이 의자에 앉습니다. 조이스틱·방향키를 움직이면 자동으로 일어나 걸어나갑니다.
- **시점**: 3인칭 카메라는 아바타 등 뒤에서 따라오고, 등 뒤에 벽이 가까우면 시점이 뒤집히지 않고 부드럽게 당겨집니다. 카메라가 몸속까지 들어올 만큼 붙으면 로봇을 잠시 감추고 눈높이 시야로 넘어갑니다(걸어나오면 바로 돌아옵니다).
- **쇼츠 모달**: 모바일에서는 폰 화면 전체를 채우는 세로 쇼츠로 열리고, `📋 종목 정보`를 누를 때만 계약 스펙·체크 포인트가 아래에서 펼쳐집니다. PC에서는 판넬 옆에 정보가 같이 보입니다.
- **사진 판넬 크게 보기**: 두 손가락으로 **1.0×~4.0× 확대·축소**, 확대한 상태에서 한 손가락으로 **상하좌우 이동**, **더블탭** 또는 오른쪽 위 `🔍 2.0× · 초기화` 로 1.0× 복원. 칸을 바꾸거나 모달을 닫으면 확대가 초기화됩니다.

## 3. 전시 구조

- 중앙홀 3면(서·북·동)에 **출입문 6개**(폭 4.4m × 높이 3.5m, 납작한 아치 + 네온 기둥)가 있고,

- 문을 지나면 독립된 전시실 — **깊이 33m** 로 넓혀 한 벽에 부스 3개(한 방 최대 7부스 = 35판넬)까지 들어갑니다:
  통화 7종목 · 지수 5 · 금리 4 · 금속 4 · 에너지 5 · 농축산물 7종목 (전시실 좌표는 서쪽 `x -46~-13`,
  북쪽 `z -44~-11`, 동쪽 `x 13~46` 로 서로 겹치지 않습니다).
  방 안은 해당 구역 색의 천장 코브·바닥 띠·조명(긴 축을 따라 등간격)·화분으로 꾸몄고, 벽마다 종목 부스가 붙어 있습니다.
- **판넬마다 바로 위에 상품명 팻말**이 붙습니다 — `유로화 #1` ~ `유로화 #5` 처럼 종목명과 칸 번호가 보이고,
  팻말을 눌러도 그 판넬이 열립니다(부스 큰 간판은 `y = 3.72`, 팻말은 `y = 2.96` 로 서로 겹치지 않음).
  팻말 170개는 **부스별 아틀라스 캔버스 1장 + 합친 메쉬 1개**로 그려 드로우콜을 아꼈습니다.
- 종목 부스 1개 = 벽면 판넬 **5칸**(5열 × 1줄). 각 칸은 그 종목의 영상 한 편과 1:1로 연결됩니다.
  `#1` 은 최신 쇼츠 자동, `#2~#5` 는 전시관에서 직접 고른 영상입니다(`5. 판넬 직접 편집`).
- 안내데스크(독도국제무역 · 인턴사원 모집)는 **중앙홀 입구(남쪽) 벽면**의 5칸 판넬 안내월로 남아 있고,

## 4. 새 쇼츠 추가하기 (1번 판넬 자동)

쇼츠를 새로 올린 뒤 아래 하나만 실행하면 **각 종목의 1번 판넬만** 최신 영상으로 바뀝니다.
2~5번 판넬(직접 고른 칸)은 건드리지 않습니다.

```bash
python3 update_shorts.py --report             # 현재 전시 현황 보기
python3 update_shorts.py --slot1-auto --dry-run   # 무엇이 바뀔지 미리보기
python3 update_shorts.py --slot1-auto          # 1번 판넬 자동 최신화 + catalog.json 갱신
python3 update_shorts.py --catalog             # catalog.json(전체 아카이브)만 다시 만들기
python3 update_shorts.py --from-cache          # 네트워크 없이 .cache/ 아카이브로 점검
python3 build.py                               # index.html 재빌드(내장 데이터 갱신)
```

- 최신 영상이 이미 **2~5번 칸**에 들어 있으면 1번과 **자리만 맞바꿉니다**(영상 유실 없음).
- 노래 쇼츠는 `SONG_KEYWORDS`·`SONG_EXACT` 블랙리스트로 자동 제외됩니다(독도방송국·전속가수 영상 포함).
- `--self-test`로 필터·1번 자동·catalog 규칙을 샘플로 점검할 수 있습니다.
- 예전 방식(`--deep` + `src/seed_exhibits.py`)은 종목별 기본값을 처음부터 다시 채울 때만 사용하세요(1번부터 새로 채우므로 2~5번 기본값도 초기화됩니다).

### GitHub Actions 로 자동화 (2시간마다)
1. `metaverse-gallery/.github-workflow-draft/update-shorts.yml` 을 리포지토리 루트의 `.github/workflows/update-shorts.yml` 로 옮깁니다.
2. 저장소 Settings → Actions → General → Workflow permissions 에서 **Read and write permissions** 를 켭니다.
3. 그러면 2시간마다 `update_shorts.py --slot1-auto && build.py` 가 돌고, 바뀐 것이 있을 때만 `exhibits.json`·`catalog.json`·`index.html` 을 `main` 에 커밋합니다.
4. GitHub 화면의 **Run workflow** 로 즉시 한 번 돌려 볼 수 있습니다.

## 5. 판넬 직접 편집 (2~5번 칸)

- 상단 바 오른쪽 **`✏️ 판넬 편집`** (또는 판넬 모달 아래 **`✏️ 이 판넬 바꾸기`**)을 누르면 편집창이 열립니다.
- 종목(18개 부스)을 고르면 `#1 ~ #5` 칸 목록이 나옵니다.
  - `#1` — **`🔄 자동 · 최신`** 배지가 붙은 잠금 칸입니다. 최신 영상 제목만 확인하고 직접 바꿀 수 없습니다(서버에서도 거부).
  - `#2 ~ #5` — `바꾸기` 로 세 가지 방법을 씁니다.
    1. **🖼️ 이미지·사진 올리기** — 폰·PC 사진 파일을 고르거나 이미지 주소(URL)를 붙여넣습니다(아래 설명).
    2. **목록에서 고르기**: `이 종목 관련` / `전체 영상`(catalog 604편) + 제목 검색.
    3. **링크 직접 붙여넣기**: `https://youtube.com/shorts/…`, `youtu.be/…`, `watch?v=…`, 11자리 ID. 제목을 비우면 유튜브 제목을 자동으로 가져옵니다.
  - `🗑️ 삭제` — 그 칸을 `새 쇼츠 대기 슬롯`으로 되돌립니다(판넬을 지웁니다).
- 저장·삭제하면 **3D 판넬 텍스처가 새로고침 없이 바로 다시 그려지고**, 접속 중인 다른 방문자의 화면에도 즉시 반영됩니다.
- 저장·삭제에는 **관리자 PIN** 이 필요합니다(아무 방문자나 판넬을 바꾸지 못하게).

### 🗑️ 판넬 삭제 (쇼츠·사진 모두)
- 판넬을 연 모달 아래 **`🗑️ 이 판넬 삭제`** 로 그 자리에서 지울 수 있습니다(`#1` 자동 칸과 이미 빈 칸에는 버튼이 나오지 않습니다).
- 실수로 눌리지 않게 **두 단계**입니다 — `이 판넬을 삭제할까요? (#3 · 제목)` 확인 → `🗑️ 삭제` → (PIN 을 아직 넣지 않았다면) 관리자 PIN → 지워집니다. 확인 단계에서 `취소` 를 누르면 아무 일도 일어나지 않습니다.
- 지우면 모달이 닫히지 않고 그 칸이 `#N · 아직 등록 전인 슬롯입니다` 로 바뀌며, 3D 벽면 판넬도 바로 `대기 슬롯` 으로 다시 그려집니다.
- 편집창에서도 같은 일을 합니다: `#2~#5` 행의 **`🗑️ 삭제`**, 펼친 칸 맨 아래 **`🗑️ 이 판넬 삭제`**.
- **새로고침해도 삭제가 유지됩니다** — 지운 칸은 서버에 `kind='empty'` 행으로 남습니다(`supabase_upgrade_delete.sql` 필요, 아래 5-1). 로컬 테스트 모드에서는 `localStorage` 에 `empty` 표식이 남습니다.

### 🖼️ 사진·이미지 판넬 (2~5번)
- `✏️ 판넬 편집` → `#2~#5` 중 한 칸을 펼치면 맨 위에 **`🖼️ 이미지·사진 올리기`** 구역이 있습니다.
- **`📁 폰·PC에서 사진/이미지 고르기`** — 폰 사진첩이나 PC 파일(JPG·PNG·WEBP)을 고르면 브라우저가 자동으로 줄입니다(긴 변 최대 1080px, WEBP 우선 · 미지원 시 JPEG, 데이터 220,000자 이하). 미리보기와 크기·용량이 나오고, 제목을 적고 **`이 이미지로 걸기`** 를 누르면 저장됩니다.
- **`🔗 이미지 링크(URL) 붙여넣기`** — `https://…/photo.jpg` 같은 주소로도 걸 수 있습니다. 단, 다른 사이트가 보안(CORS) 설정으로 이미지를 막으면 3D 벽면에는 `사진` 자리표시만 나오고 **크게 보기에서는 원본이 그대로** 보입니다(그럴 때는 사진 파일로 올리는 편이 확실합니다).
- 사진이 걸린 판넬은 3D 벽면에서 흰 카드 대신 **사진이 크게 걸린 판넬**(아래에 `#N · 제목 · 눌러서 크게 보기`)로 바뀌고, 누르면 유튜브 대신 **사진이 화면에 맞춰 크게** 열립니다.
- `#1` 은 지금처럼 **최신 쇼츠 자동**이라 사진을 걸 수 없습니다(사진도 `#2~#5` 에만).
- 실시간: 사진은 용량이 커서 접속자에게 데이터를 직접 보내지 않고 **`이 칸이 바뀌었다`는 신호만** 보낸 뒤, 받은 쪽이 그 칸만 서버에서 다시 읽습니다.
- ※ 사진 저장은 DB 업데이트가 먼저 필요합니다 — 아래 `supabase_upgrade_image.sql`(또는 새 `supabase_setup.sql`)을 실행하기 전에는 `DB 이미지 업데이트 SQL을 먼저 실행해 주세요` 안내가 뜹니다.

## 7. 음성 대화

### 1단계 — 말로 쓰기 (지금 동작)
- 채팅 입력줄의 **🎤** 버튼 → 브라우저 `SpeechRecognition`(`ko-KR`)으로 말을 받아 **채팅 + 말풍선**으로 바로 전송합니다.
- 지원: Chrome·Edge·Safari(일부), **HTTPS 또는 localhost** 필요.
- 미지원 브라우저나 `file://`에서는 `HTTPS 배포 또는 지원 브라우저에서 음성 입력 가능` 안내만 뜨고 에러는 나지 않습니다.

### 2단계 — 실시간 음성방 (서버 연결 시 동작)
- **채널은 층으로 갈린다**: 1층 중앙홀·전시실 = `gallery`, 2층 회의실 = `meeting`. 메시지(`hello`·`voice-hello`·`rtc-offer/answer/ice`·`voice-bye`)는 **같은 `room` 방문자끼리만** 받아들인다.
- **1층 중앙홀·전시실**: 오른쪽 아래 **`🎙️ 음성 대화`** 단추(같은 층 방문자가 있거나 이미 켰을 때만 보임)를 누르면 그 자리에서 만난 방문자와 바로 음성 대화. 상대가 먼저 켜면 토스트 + 단추가 반짝이며 한 번만 누르면 연결된다.
- **2층 회의실**: 회의실 상단 **`2층 회의실 · 음성 회의`** 바의 `마이크 켜기`.
- 채팅창 상단 **🎙️ 음성방** 버튼 → 지금 층에 맞는 안내 패널. `meta.realtime`이 설정돼 있으면 버튼이 활성화됩니다.
- 방식: `getUserMedia` 마이크 → 방문자끼리 `RTCPeerConnection` 연결(피어마다 `<audio>` 1개),
  SDP offer/answer·ICE 후보는 위 Realtime Broadcast(`rtc-offer` / `rtc-answer` / `rtc-ice`)로 교환합니다.
- **ICE 서버(2026-11-28)**: STUN 3개(Google 2 · Cloudflare 1) + **TURN 4개**(`turn.evan-brass.net` 3478 UDP / 443 TLS,
  `turn.quickblox.com` 3478, `turn.bettercrewl.ink` 3478). 서울↔지방↔외국, LTE/5G 대칭 NAT(CGNAT)에서도
  직결이 막히면 릴레이로 붙는다(바에 `· 원거리 중계` 표시). 바꾸려면 `window.GALLERY_RTC_ICE` 로
  `[{urls, username, credential}]` 을 넣으면 그 목록이 우선한다(예: Metered·Cloudflare 전용 TURN 자격 증명).
- 층을 옮기면(`setFloor`) 음성을 먼저 끊고 `voice-bye` 를 보낸 뒤 새 `room` 을 `hello`/`state` 로 알린다 — 1층 대화와 2층 회의 음성이 섞이지 않는다.
- 설정이 없으면 버튼이 **비활성** 상태로 `2단계 서버 연결 필요`를 표시합니다. **가짜 연결·가짜 참가자는 만들지 않습니다.**
- **연결 상태 표시**: 2층 음성 바·노래방 안내문·채팅 음성 패널에 `실시간 음성 연결됨 · N명`(듣기만 하면 `듣는 중 · N명`)이
  실제 연결된 피어 수로 뜬다. 자동재생이 막히면 `🔊 화면을 한 번 누르면 상대 소리가 켜집니다` 로 알린다.
- **자동 복구**: 시그널링 WebSocket 이 끊기면(폰 화면 꺼짐·LTE↔와이파이) 1~15초 간격으로 다시 붙고,
  붙는 순간 `hello`/`voice-hello` 를 다시 보내 연결을 되살린다. 잠깐 `disconnected` 되면 ICE 재시작으로 잇는다.
- **전체 수신**: 마이크를 켜지 않은 사람도 같은 `room` 이면 듣기 전용(`recvonly`)으로 연결되고,
  3D 거리와 무관하게 같은 방이면 모두 들린다(거리 감쇠 없음). 한 명이 켜 둔 뒤 다른 사람이 들어와도,
  마이크를 껐다 켜도 이어지도록 빈 `RTCPeerConnection` 을 미리 만들지 않는다.
- **노래방 마이크**: 잡음 억제(`noiseSuppression`)는 끄고 에코 캔슬만 켠다 — 잡음 억제가 노래의 숨소리·여운을 깎기 때문.
  유튜브 반주(MR)는 저작권·브라우저 정책상 각자 기기에서 재생되고, WebRTC 로 넘어가는 것은 마이크를 탄 목소리다.
- **노래방 마이크 자동 복구(2026-11-28)**: 🔍 반주 찾기로 유튜브 앱·새 창에 다녀오거나 폰 화면이 꺼졌다 켜지면
  안드로이드가 `AudioContext`(`MIC.ctx`)를 `suspended`/`interrupted` 로 멈추고 마이크 트랙을 `ended`/`muted` 로 바꾼다 —
  그대로 두면 화면엔 `켜짐` 인데 2층에는 무음이 간다. 그래서 `AudioContext` 상태 변화 · 트랙 `ended`/`muted` ·
  `visibilitychange`/`focus`/`pageshow` · 반주 재생 직후(0.4·1.2·2.5초) · 5초 주기 감시에서 스스로 `resume()` 하고,
  죽은 트랙은 `getUserMedia` 로 다시 열어 모든 피어의 송신 트랙을 `replaceTrack` 으로 교체한다(가수가 마이크를 껐다 켤 필요 없음).
  상대 쪽 `<audio>` 가 멈춰 있으면 다시 재생하고 끊긴 피어는 재연결한다(`VOICE.revive`).
  탭이 버려져 브라우저가 페이지를 새로 연 경우는 저절로 켜지지 않으므로 창에 `마이크 켜기를 한 번 눌러 주세요` 로 안내한다.
  검증용: `__gallery.karaoke.mic.state()` · `mic.heal()` · `mic.reopen()`.
- 운영 시 권장: 방 인원이 많아지면 SFU(LiveKit·Daily)나 전용 TURN(coturn·Metered) 으로 교체.

## 8. 2단계(다중접속·배포) 확장 구조

1. **데이터**: `exhibits.json`은 그대로 두고, 쇼츠 갱신만 `update_shorts.py`가 담당.

3. **음성**: 위 WebRTC 훅(공개 TURN 포함), 방 인원이 많아지면 SFU(LiveKit·Daily 등)로 교체.

5. **배포**: 정적 호스팅에 `index.html` + `exhibits.json` 업로드. HTTPS면 음성 입력·마이크 권한이 모두 동작합니다.

  (방은 `2.00 × 3.53m`, 화면 9:16 `1.86 × 3.31m`). 부스는 문 쪽에서 **3.8m** 띄워 TV·화분과 겹치지 않습니다.
- 화면을 누르거나 가까이서 보면 `📺 {방} 뉴스 TV · 크게 보기` 알약이 뜨고, 누르면 그 방 뉴스가 모달로 열립니다.
  모달 위 **방 선택 탭(중앙홀·통화·지수·금리·금속·에너지·농축산물)** 으로 다른 방 뉴스도 바로 볼 수 있습니다.
- `news.json` 의 `rooms.fx`·`index`·`rates`·`metals`·`energy`·`ags` 가 방별 뉴스(각 6건)입니다.
- 성능: 캔버스를 7장 매 프레임 다시 그리면 프레임이 무너져서, **지금 서 있는 방(또는 모달)의 TV 만 15fps**,
  다른 방 TV 는 5초에 한 번만 다시 그립니다(스크롤 값은 계속 올라가 이어짐). 정지 배경(헤더·페이드)은 한 번만 그려 캐시합니다.

### 위치
- 중앙홀 **남쪽 입구 벽**에서 홀 안을 바라볼 때 **오른쪽 끝(-X)** — 모서리 기둥(`x = -12.5`)과
  `독도국제무역` 안내데스크 부스(`x = -9.19`) 사이의 빈 벽면에 세로 스마트폰형 TV 가 걸려 있습니다.
- `TV 중심 x = -10.95, y = 2.65, z = 12.72` — 하단 `0.71m`, 상단 `4.59m` 로 **바닥~사람 눈높이**에 서 있고
  천장 몰딩(`5.95m`)에서 `1.36m` 떨어져 **천장에 붙지 않았습니다**. 화면은 홀 안쪽(-Z)을 향합니다.
- `재롱둥이 머니 쇼츠` 배너는 TV 가 오른쪽 끝으로 간 만큼 **남쪽 벽 가운데(`x = 1.0`, 폭 `13.6m`, 높이 `1.9m`)** 로
  되돌려 균형을 맞췄습니다(배너 왼쪽 `-5.8m` ↔ TV 오른쪽 `-9.85m`).
- TV 앞 시야를 가리던 남서쪽 화분은 **서쪽 벽 옆(`x = -12.1, z = 2.9`)** 으로 옮겼습니다.

### 화면 · 스크롤
- 화면은 **세로 스마트폰 9:16** — 베젤 포함 `2.20 × 3.88m`, 실제 화면 `2.04 × 3.63m`(`9:16`).
  상단 골드 프레임 + 스피커·카메라, 하단 골드 홈바 스트립과 녹화 LED 로 폰·키오스크 느낌을 냅니다.
- 캔버스는 **`720×1280`**(세로, 헤더 `112px`) CanvasTexture(`toneMapped: false`)에 직접 그립니다 — 위쪽 고정 헤더
  `📺 국제상품 주요 뉴스 · 매일 09:30 갱신` + `LIVE` 배지 + 기준 날짜, 그 아래 뉴스 카드(한 화면에 4~5건).
- 카드는 **손대지 않아도 저절로 아래에서 위로 초당 약 24px** 로 천천히 흐르고(보이는 TV 는 15fps 갱신), 목록을 2벌 이어 그려
  `scrollY % contentH` 로 **끊김·점프 없이 무한 반복**합니다(속도는 `news.json` 의 `meta.scroll_px_per_sec`).
- 3D 화면에서도 기존 확대·축소가 그대로 통합니다 — 두 손가락 **0.65×~3.2×**, PC `Ctrl`+휠,
  확대 중이면 오른쪽 `🔍 n× · 초기화` 알약으로 복원.

### 크게 보기 (모달)
- 여는 방법: TV 화면 **탭/클릭** · TV 앞에서 `E` · 아래 알약 `📺 국제상품 뉴스 TV · 크게 보기` ·
  상단 `📺 뉴스TV` 버튼(TV 정면 자리로 이동).

  `visualViewport`(없으면 `innerWidth/innerHeight`)에서 헤더·방 탭·아래 단추줄·안내문이 차지하는 높이를 뺀

  `visualViewport resize` 마다 다시 맞추고, 확대(줌) 위치도 새 무대 안으로 다시 잠급니다.
- **세로 화면 · 일반 데스크톱**: 9:16 세로 스마트폰 비율(720×1280). 세로 폰(390×844)에서 무대 높이가 화면의 약 **68%**,

## 11. 💁 프런트데스크(중앙홀 남쪽 벽) — 루아 · 도현 · 음성 안내 (2026-11-20 개편)

중앙홀 **남쪽 벽 앞(‘독도국제무역.com에 방문을 환영합니다’ 배너 아래)** 에 곡선형 대리석·월넛·골드 카운터를 두고,
카운터 뒤에 **여자 안내원 `루아`(깜찍·발랄)** 와 **남자 컨시어지 `도현`(정중·세련)** 이 남쪽 벽을 등지고 중앙홀(`-Z`)을 바라본다.
방문객이 카운터를 클릭·터치하거나, 앞에 다가가 `E`/안내 알약을 누르면 **프런트데스크 상담 창**이 열린다.

### 구조

| 요소 | 내용 |
| --- | --- |
| 위치 | 중앙홀 남쪽 벽 앞(`cx = 0`, 카운터 `z ≈ 9.6~10.1`, 루아·도현 `z ≈ 10.98`) — 앞면이 `-Z`(중앙홀)을 향하도록 카운터 곡률을 180° 돌렸다. 방문객은 `z ≈ 7.8~8.8` 에서 마주 본다 |
| 카운터 | 곡률 반지름 7.6m · 좌우 21° 곡선(폭 약 6m, 두께 0.5m, 상판 높이 1.06m). 좌우 통로를 가리지 않아 중앙홀·6개 전시실 동선이 그대로 유지된다 |
| 재질·조명 | 대리석 상판 + 월넛 몸통 + 골드 트림·리브, 바닥 웜 글로우 |
| 소품 | 카운터 안내 모니터(뉴스 TV 건수·갱신 시각 자동 반영), `루아`·`도현` 명패, 화병 |
| 푯말 | **카운터 앞면에 직접 붙인 `독도국제무역 프런트데스크` 푯말**(영문 `DOKDO INTERNATIONAL TRADE · FRONT DESK`). **천장에 매달리던 큰 간판·매다는 줄·천장 코브는 모두 제거**했고, 간판·모니터·안내문에서 `AI 안내` 문구를 지웠다 |
| 캐릭터 | 사람 조형(머리·목·얼굴·재킷·팔·다리·구두)으로 따로 제작. 루아 = 코랄 재킷·리본·트윈번·큰 눈·통통 튀는 idle·손 흔들기, 도현 = 네이비 정장·골드 넥타이·라펠 핀·안경·단정한 자세·정중한 끄덕임. 머리 위 이름표 `루아 · 안내` / `도현 · 컨시어지` |
| 근접 인사 | 방문객이 카운터 앞 **4m** 안에 들어서면 루아 또는 도현이 **3D 말풍선 + 제스처(손 흔들기/끄덕임) + 한국어 음성**으로 먼저 인사한다(한 사람당 45초 쿨다운·간격 6초로 도배 방지) |
| 반응 | 답변이 나오면 그 캐릭터가 3D 말풍선 + 제스처로 반응하고, 방문객 쪽으로 고개를 살짝 돌린다 |

### 첫 방문자 안내

- 입장 직후(닉네임 창을 닫은 뒤) **`👋 앞쪽 프런트데스크로 다가가거나 루아·도현을 누르면 음성·채팅 대화를 시작할 수 있어요`** 안내 배너를 띄운다(상단 구역 바 아래·버튼을 가리지 않는 자리, 한 번 보면 저장되어 다시 뜨지 않음).
- 데스크 앞에서는 알약이 **`💬 루아·도현을 누르거나 E 키로 대화를 시작하세요`** 로 바뀌고, 알약을 누르면 바로 상담 창이 열린다.
- 상담 창 안에는 입력창 위에 **`아래 질문 버튼을 누르거나 글을 입력하고 · 🎤 마이크로 말을 걸어 보세요. 목소리로도 답해 드려요.`** 한 줄 안내가 늘 있다.

### 목소리 답변 (한국어 TTS)

- `🔊 목소리 응답 ON/OFF` 토글(기본 ON, `mg_voice_on_v1` 저장)과 각 답변 옆 **`🔊 다시 듣기`**, 상단 **`⏹ 정지** 버튼.
- 루아는 밝고 부드러운 톤(pitch 1.16), 도현은 차분하고 낮은 톤(pitch 0.86) — `ko-KR` 음성이 두 개 이상이면 서로 다른 목소리를 쓴다.
- 브라우저 자동재생 정책 때문에 **첫 터치 전에는 말을 걸지 않고 대기**했다가, 첫 터치·키 입력 직후 대기 중이던 인사를 바로 재생한다(그 전에는 화면 말풍선 + `화면을 한 번 터치하면 목소리로도 안내해 드려요` 토스트).

### 상담 창 (`#desk-modal`)

- 상단에서 **👧 루아(깜찍·발랄)** / **🧑 도현(정중·세련)** 전환 — 캐릭터마다 대화 기록이 따로 쌓인다.
- 추천 질문 칩: `오늘 핵심 시장 뉴스` · `전시실·종목 안내` · `쇼츠 추천해 줘` · `매매 지표(MACD·CCI) 설명`
- 텍스트 입력 + 음성 입력(`🎤`, 지원 브라우저·HTTPS에서만) + 전송.
- 답변에 추천 구역/종목이 있으면 **바로 이동 버튼**(`금속 전시실로 이동`, `골드 부스로 이동`)이 답변 아래에 붙는다.
- 상태 배지: **`AI 실시간 두뇌 연결됨 · 모델명`** ↔ **`전시관 내장 안내 모드 (AI 키 연결 대기)`**.
  Edge Function이 아직 배포되지 않았거나 오류·한도 초과여도 **에러 팝업 없이** 내장 안내 모드로 정확히 답한다.

### 전달 문맥 크기 제한 (2026-11-20 — Groq 413 대응)

브라우저가 매 질문마다 보내는 `context` 는 **`JSON.stringify(context).length ≤ 5,500자**로 묶는다(`DESK_CTX_MAX`).
무료 티어 Groq(`openai/gpt-oss-120b`)의 분당 8,000토큰(TPM) 한도에서 `HTTP 413 Request too large` 가 나
AI 대신 내장 폴백이 답하던 문제를 없앤다.

- `gallery` — 이름·채널·구조·전시 규모·지표·원칙 6줄 요약
- `news` — 중앙홀 7건은 `{tag, headline, price, change, line}` 한 줄 요약, 방별 뉴스는 **질문이 가리킨 방만** 4건 상세(다른 방은 대표 헤드라인 1줄)

## 12. 🏛️ 2층 회의실 · 회의실 포털 · 직원 등급 A·B · 음성 회의 (2026-11-20 추가)

### 오가는 길 — 양방향 포털

| 포털 | 위치 | 간판 | 동작 |
| --- | --- | --- | --- |
| `회의실` | 중앙홀 동쪽 빈 벽면(`x ≈ 12.3, z ≈ 0.6`, 에너지 문 `z=-5.5` · 농축산물 문 `z=+6.5` 사이) | **회의실** | 누르거나 `E` → **회의실 입장 인증 창**(이름 + 입장 코드) |

### 입장 인증 · 직원 등급 (A·B·C)

- 입장 창: **이름 + 입장 코드**. 직원 개인 코드 또는 관리자가 정한 **공용 A·B 코드**로 들어간다.
- 통과 조건: 명단에 등록된 **A·B 등급**만 · **C 등급은 공용 코드로도 입장 불가** · 명단에 없는 이름은 공용 코드가 맞으면 B 등급으로 입장(관리자 설정으로 막을 수 있음).
- **⚙️ 직원 등급 관리**(관리자 PIN `verify_gallery_pin` 통과 후) — 직원 추가/등급 변경(A·B·C)/개인 입장 코드 설정/삭제, **공용 A·B 코드 변경**. 공용 코드는 DB에 bcrypt 해시로만 저장되고 화면·파일에는 남지 않는다.
- 관리자는 입장 창의 `🔑 관리자 PIN으로 입장` 으로 회의실을 바로 시험할 수 있다.
- DB 미적용(`PGRST202`/`PGRST205`)이면 “직원 명단 DB가 아직 적용되지 않았습니다” 안내 후 관리자 PIN 입장으로 매끄럽게 넘어간다.

### 음성 = 1층 중앙홀 대화 · 2층 회의실 회의

- **2층 회의실**: 회의실에 있는 동안 상단에 **`2층 회의실 · 음성 회의`** 바가 뜨고 `마이크 켜기` 로 참여한다(WebRTC + Supabase Realtime, 채널 `room: 'meeting'`).
- **1층 중앙홀·전시실**: 오른쪽 아래 인사 단추 줄의 **`🎙️ 음성 대화`** 를 누르면 그 자리에서 만난 방문자와 바로 음성 대화(채널 `room: 'gallery'`). 같은 층 방문자가 있거나 이미 켰을 때만 보이고, 켜져 있으면 `🎙️ 대화 중` 으로 강조된다.

## 14. 🔐 관리자 전용 방문자 현황 (2026-11-21 추가) — 일반 방문자에게는 인원수 비공개

전시관에 **몇 명이 들어왔는지 나만** 볼 수 있게 했다. 일반 방문자 화면에는 인원수가 **어디에도** 나오지 않는다.
